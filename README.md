# NPC Rwanda Frontend Redesign

This project is a complete frontend redesign for the National Paralympic Committee of Rwanda (NPC Rwanda). It focuses on modern aesthetics, professional branding, and accessibility.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom design system (located in `assets/css/style.css`).
- **Bootstrap 5**: Responsive grid and components.
- **AOS (Animate On Scroll)**: Subtle micro-animations.
- **Font Awesome**: Professional iconography.

## Folder Structure
- `/assets/css/style.css`: Main stylesheet containing the brand color palette and typography.
- `/assets/js/main.js`: Shared JavaScript logic.
- `/assets/img/`: Placeholder for images (using high-quality Unsplash/Pexels URLs for demo).
- `index.html`: Homepage.
- `about.html`: History, Vision, Mission, and Leadership.
- `sports.html`: Details on Sitting Volleyball, Wheelchair Basketball, etc.
- `athletes.html`: Directory of featured athletes with filters.
- `news.html`: Latest updates and events.
- `governance.html`: Transparency documents and organizational structure.
- `contact.html`: Contact form, location details, and map.

## Key Features
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Accessibility**: Skip links, ARIA labels, and high contrast colors.
- **Modern UI**: Rounded corners, soft shadows, and smooth hover effects.
- **Brand Identity**: Aligned with Rwandan national colors (Blue, Yellow, Green).

## Implementation Details
The redesign follows the proposal objectives to move away from basic templates and provide an internationally competitive interface that serves persons with disabilities through better UX/UI.
